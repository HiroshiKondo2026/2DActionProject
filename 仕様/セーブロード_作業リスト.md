# セーブ/ロード 作業リスト

Phase D（セーブ/ロード）の実装タスク。上から順に進めるのが安全（土台 → 機能 → UI連携）。
凡例： 💻=コード実装（担当:AI） / 🎮=Unity側作業（担当:あなた） / ✅=完了チェック

---

## 確定した仕様（前提）

- セーブ内容：**進行状況のみ**（現在HP / 最大HP / シーン名 / 所持品 / 装備 / **撃破済みEnemyID** / timestamp）。CSV調整値は保存しない
- スロット：2つ（オートセーブ用 / 通常セーブ用）
- LoadGame：**オート/通常を選ばせる**（LoadGame → スロット選択 → ロード実行）
- オートセーブ発火：**`AutoSaveOnEnter` を置いたシーンの入場時のみ**（Stage*-1系・Title・GameOverには置かない）
- ロード粒度：シーン境界（頭からロード ＋ 保存HP/所持品で開始）
- **Enemy永続化**：撃破済みEnemyはロード時に復活させない。生き残りだけフルHPで再配置（farming防止）

## メモ・懸念（進行中に埋めていく）

- LoadGame のスロット選択UIは Title と Menu で共通化できると管理が楽
- 「初めて入ったときの状態」＝敵状態・座標は保存しない（シーンを頭からロード）方針
- timestamp は表示にも使える（「オート: 12:34 / 通常: 昨日」等）が、まずは内部比較用でよい
