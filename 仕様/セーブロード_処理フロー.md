# セーブ/ロード：処理フロー

セーブ/ロードのデータの流れを図でまとめる（STEPを進めるごとに拡張していく）。

---

## STEP 1 時点：土台（ディスクI/Oのみ）

STEP1では「SaveDataをディスクに読み書きする最下層」だけを用意した。
実際に「現在の状態を集める」処理はSTEP2、「ロードして復元・遷移」はSTEP3で追加する。

### 保存（書き込み）

```text
SaveData（進行状況を詰めた構造体）
   │  ※STEP1ではダミー。実際の収集はSTEP2で実装
   ▼
SaveSystem.Save(slot, data)
   ├─ data.savedAtTicks = 現在時刻
   ├─ JsonUtility.ToJson(data) でJSON文字列化
   └─ File.WriteAllText(パス, json)
         └─ 保存先： Application.persistentDataPath/save_auto.json（または save_manual.json）
   （失敗しても LogError のみでゲームは継続）
```

### 読み込み（読み出し）

```text
SaveSystem.Load(slot)
   ├─ File.Exists(パス)?
   │     └─ 無ければ null（＝セーブなし。正常系）
   ├─ File.ReadAllText(パス)
   └─ JsonUtility.FromJson<SaveData>(json)
         ├─ 成功 → SaveData を返す
         └─ 壊れている → LogError＋null（呼び出し側はNewGame相当へ倒す）
```

### 全体像（STEP1のスコープ）

```text
        ┌──────────────── STEP1で用意した部分 ────────────────┐
        │                                                      │
 SaveData ──► SaveSystem.Save ──► persistentDataPath/*.json    │
 SaveData ◄── SaveSystem.Load ◄── persistentDataPath/*.json    │
        │                                                      │
        └──────────────────────────────────────────────────────┘

 ↑ この上に、STEP2「現在状態の収集」、STEP3「GameDataへ復元＋シーン遷移」を乗せる
```

### スロット構成

| スロット | ファイル | 用途 |
| --- | --- | --- |
| `Auto` | `save_auto.json` | オートセーブ（セーブ点シーン入場時に上書き） |
| `Manual` | `save_manual.json` | 通常セーブ（メニューのSaveで上書き） |
